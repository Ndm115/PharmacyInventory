HEALTHFIRST PHARMACY INVENTORY MANAGEMENT SYSTEM
=================================================

Programming 732 Assignment

PROJECT DESCRIPTION
-------------------
The Pharmacy Inventory Management System (PIMS) is a Java desktop
application developed for HealthFirst Pharmacy.

The system is being developed using Java Swing/AWT for the graphical
user interface and JDBC for connecting the application to a MySQL
database.

The purpose of the system is to assist the pharmacy with managing
medicines, suppliers, users, sales and inventory information.


CURRENT FEATURES
----------------
- MySQL database connection
- User login system
- Role-based authentication for Admin and Cashier users
- Medicine management
- Supplier management


TECHNOLOGIES USED
-----------------
- Java
- Java Swing/AWT
- JDBC
- MySQL
- NetBeans IDE


DATABASE
--------
Database Name: pharmacy_inventory

The database stores information about:
- Users
- Suppliers
- Medicines
- Sales
- Sale items
